## 📖 О проекте
J-LIGA.KZ — это полноценная платформа для организации и управления любительскими футбольными лигами. Включает в себя публичный сайт с турнирными таблицами, календарем матчей, статистикой игроков и мощную административную панель для автоматизации всех процессов.

## 🚀 Ключевые возможности
- **Мульти-турнирность**: Поддержка чемпионатов, кубков, групповых этапов и плей-офф.
- **Автоматический пересчет**: Очки, голы, карточки и бомбардиры пересчитываются мгновенно после ввода событий.
- **Дисквалификации**: Автоматическое списание матчей за красные карточки и накопления ЖК.
- **Заявки и Ростеры**: Управление составами команд на каждый турнир.
- **Парсер**: Встроенный модуль синхронизации данных с внешних источников.
- **Медиа**: Все логотипы и фото хранятся локально на сервере (независимость от третьих лиц).

## 🛠 Технологии
- **Бэкенд**: FastAPI, SQLAlchemy (Async), Alembic.
- **База данных**: PostgreSQL.
- **Фронтенд**: Jinja2, Bootstrap 5, Vanilla JS.
- **Тестирование**: Pytest.
- **Деплой**: Docker, Docker Compose.
